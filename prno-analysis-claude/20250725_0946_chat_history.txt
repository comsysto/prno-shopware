> What is HMR development?

● HMR stands for Hot Module Replacement (also called Hot Module Reload). It's a development feature that allows you to see code changes instantly in your browser without having to
   manually refresh the page or lose your application state.

  How HMR Works

  When you make changes to your code during development:

  1. Traditional Development: You'd need to refresh the browser, losing any form data, navigation state, etc.
  2. With HMR: The development server detects file changes and automatically updates only the specific modules that changed, preserving your application state.

  In Shopware Context

  When you run:
  composer watch:admin        # Administration HMR server
  composer watch:storefront   # Storefront HMR server

  You get:
  - Instant Updates: Changes to Vue components, SCSS, or JavaScript appear immediately
  - State Preservation: Forms stay filled, modals remain open, navigation state persists
  - Faster Development: No manual refreshing or re-navigating to test changes

  Development URLs with HMR

  - Administration HMR: http://localhost:5773 - Vue 3 admin interface with instant updates
  - Storefront HMR: http://localhost:9998 - Customer interface with live reloading
  - Main Application: http://localhost:8000 - The actual Shopware instance

  Benefits for Shopware Development

  - Administration: Vue component changes update instantly while preserving complex form states
  - Storefront: CSS/SCSS changes apply immediately without losing shopping cart contents
  - Productivity: Significantly speeds up the development cycle, especially for UI work

  HMR is particularly valuable in Shopware because the administration interface is complex (lots of forms, modals, navigation states) and the storefront has intricate user flows
  (cart, checkout process) that would be tedious to manually recreate after each refresh.
